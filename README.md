# VidzHub 🎬

VidzHub is a modern, mobile-first web application for streaming anime and videos. It is designed to be installed directly on your phone as a Progressive Web App (PWA), giving you a native app experience right from the browser.

## ✨ Features

- **Dynamic Hero Slider:** Auto-sliding banner with manual swipe and dot navigation.
- **Videocon Player:** Custom-built HTML5 video player with seek, volume, fullscreen, and loading states.
- **Continue Watching:** Horizontal scrolling list of recently watched media.
- **Social Sharing:** Built-in share buttons for WhatsApp, X (Twitter), Reddit, and Messenger.
- **PWA Ready:** Can be installed to your phone's home screen for full-screen, offline-capable usage.

## 🛠️ Built With

- **HTML5** - Structure and layout
- **CSS3** - Custom dark-themed styling, gradients, and flexbox layouts
- **Vanilla JavaScript** - Slider logic, player controls, and DOM manipulation
- **PWA** - Manifest and Service Worker for offline capabilities
